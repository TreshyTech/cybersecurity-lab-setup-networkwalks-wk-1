# Network Walks — Week 1 Cybersecurity Lab Setup

## Overview

This repository documents my Week 1 practical activities during the Network Walks cybersecurity training. The focus was on preparing a virtual lab environment for cybersecurity learning and hands-on practice.

## Objectives

- Set up a virtual lab using Oracle VirtualBox.
- Install and configure Kali Linux as a virtual machine.
- Configure the virtual network and IP addressing.
- Explore shared folders and clipboard integration between the host and virtual machine.
- Document the setup process with screenshots.

## Lab Environment

- **Virtualization platform:** Oracle VirtualBox
- **Operating system:** Kali Linux
- **Network configuration:** Virtual NAT Network
- **Purpose:** Cybersecurity learning and authorized lab practice
